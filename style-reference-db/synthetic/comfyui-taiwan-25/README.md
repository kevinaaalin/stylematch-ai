# 台灣常用 25 風格第二圖片庫

本圖庫以 TWCID 設計作品頁的 23 個網站風格 ID 為基礎，套用指定的 5 組名稱調整，並新增「精品飯店風」與「奶油風」，共 25 類。

## 規格

- 每類 50 張，完成目標共 1,250 張。
- 尺寸：1216 × 832 PNG。
- 生成：本機 ComfyUI、SDXL Base、DPM++ 2M / Karras、28 steps、CFG 6.5。
- 每類固定 10 種收納重點空間 × 5 種光線／拍攝方式。
- 空間特別增加櫥櫃、書櫃、衣櫃、鞋櫃、展示櫃、浴櫃與商業陳列櫃。
- `manifest.jsonl` 保存每張圖的風格、來源 style ID、空間、seed、提示詞、模型與 ComfyUI 任務 ID。
- `taxonomy.json` 保存 25 類中英文名稱與 TWCID 來源分類。

第一個 30 風格圖庫保留於相鄰的 `comfyui/`，兩套資料不混合。
