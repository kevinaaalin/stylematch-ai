# ComfyUI 合成風格測試集

此資料集由本機 ComfyUI 與 `sd_xl_base_1.0.safetensors` 生成，和 TWCID 真實案例資料分開保存。

## 生成規格

- 目標：StyleMatch AI 完整 30 種風格，每類 50 張，共 1,500 張。
- 空間：客廳、臥室、餐廳、廚房、浴室、商業空間、書房、玄關、閱讀角落、開放式客餐廳。
- 變化：日間廣角、日間細節、黃昏廣角、夜間細節、陰天斜角構圖。
- 尺寸：1216 × 832。
- 採樣：DPM++ 2M / Karras、28 steps、CFG 6.5。
- 每張圖使用固定且可重現的 seed。
- `manifest.jsonl` 記錄分類、空間、光線、seed、模型、完整正負提示詞與 ComfyUI 任務 ID。

## 目標分類

涵蓋 StyleMatch AI `styleCatalog.js` 的全部 30 種標準分類。每類固定採用相同的 10 種空間與 5 種拍攝／光線變化，便於類別間比較。資料夾使用「中文名稱_英文ID」命名。

合成圖適合功能測試、分類邊界測試及 UI 展示；模型最終準確率仍應使用獨立的真實攝影資料集評估。
