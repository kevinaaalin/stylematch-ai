# 2. Responsibility

Authentication Module 負責：

- Identity Verification
- Login
- Logout
- Token Issue
- Refresh Token
- Session Control
- MFA
- Device Registration
- Login Audit

Authentication 不負責：

- Authorization（IS-005）
- RBAC
- ABAC
- Organization
- User Profile

# 9. SQL

```sql
CREATE TABLE auth_session(

session_id BIGINT PRIMARY KEY,

user_id BIGINT NOT NULL,

tenant_id BIGINT,

organization_id BIGINT,

device_id VARCHAR(100),

refresh_token_hash CHAR(64),

access_expired_at TIMESTAMP,

refresh_expired_at TIMESTAMP,

status VARCHAR(30),

created_at TIMESTAMP

);
```

---

```sql
CREATE TABLE auth_login_history(

login_history_id BIGINT PRIMARY KEY,

user_id BIGINT,

login_ip VARCHAR(100),

user_agent TEXT,

device_name VARCHAR(200),

result VARCHAR(20),

trace_id VARCHAR(100),

created_at TIMESTAMP

);
```
