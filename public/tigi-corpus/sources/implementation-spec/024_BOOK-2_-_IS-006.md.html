# 2. Responsibility

Case Module 負責：

- Case Lifecycle
- Case Identity
- Case Metadata
- Project Binding
- Customer Binding
- Organization Binding
- Workflow Initialization
- Governance Entry Point
- Case Status Management
- Case Archive

Case Module 不負責：

- Workflow Execution（IS-007）
- State Machine（IS-008）
- Gate Decision（IS-009）
- Evidence（IS-011）
- Payment（IS-013）

---

# 3. Business Rules

CASE-001

Case Number 全平台唯一。

---

CASE-002

Case UUID 永久不可變。

---

CASE-003

Case 建立後自動建立：

- Workflow
- Audit
- Timeline
- PGP Container

---

CASE-004

Case 必須屬於：

- Tenant
- Organization
- Project
- Customer

---

CASE-005

Case 建立後不得變更 Tenant。

---

CASE-006

Case 必須指定 Responsible Organization。

---

CASE-007

Case 所有異動皆產生 Audit。

---

CASE-008

Case Archive 後唯讀。

---

CASE-009

Case 不允許 Hard Delete。

---

CASE-010

Case 必須有 Governance Status。

# 9. SQL

```sql
CREATE TABLE case_master(

case_id BIGINT PRIMARY KEY,

case_uuid CHAR(36) UNIQUE,

case_no VARCHAR(50) UNIQUE,

tenant_id BIGINT,

organization_id BIGINT,

project_id BIGINT,

customer_id BIGINT,

case_type VARCHAR(50),

title VARCHAR(255),

status VARCHAR(30),

risk_level VARCHAR(20),

workflow_id BIGINT,

created_at TIMESTAMP,

updated_at TIMESTAMP,

archived_at TIMESTAMP

);
```

---

```sql
CREATE TABLE case_metadata(

metadata_id BIGINT PRIMARY KEY,

case_id BIGINT,

budget_amount DECIMAL(18,2),

expected_start DATE,

expected_finish DATE,

building_type VARCHAR(50),

floor_area DECIMAL(10,2),

remark TEXT
);
```

---

```sql
CREATE TABLE case_tag(

tag_id BIGINT PRIMARY KEY,

case_id BIGINT,

tag_name VARCHAR(100)
);
```
