# 2. Responsibility

Payment Engine 負責：

- Payment Plan
- Milestone Payment
- Escrow Account
- Payment Request
- Payment Approval
- Payment Release
- Refund
- Settlement
- Invoice
- Reconciliation
- Financial Audit
- PGP Binding

Payment Engine 不負責：

- Banking Transfer
- ERP Accounting
- Tax Declaration
- Financial Reporting

# 14. SQL

```sql
CREATE TABLE payment_master(

payment_id BIGINT PRIMARY KEY,

case_id BIGINT,

contract_id BIGINT,

workflow_id BIGINT,

milestone_code VARCHAR(30),

payment_type VARCHAR(50),

amount DECIMAL(18,2),

status VARCHAR(30),

created_at TIMESTAMP

);
```

```sql
CREATE TABLE escrow_account(

escrow_id BIGINT PRIMARY KEY,

payment_id BIGINT,

account_no VARCHAR(100),

balance DECIMAL(18,2),

status VARCHAR(30),

updated_at TIMESTAMP

);
```

```sql
CREATE TABLE payment_invoice(

invoice_id BIGINT PRIMARY KEY,

payment_id BIGINT,

invoice_no VARCHAR(50),

invoice_type VARCHAR(50),

issued_at TIMESTAMP

);
```

```sql
CREATE TABLE payment_settlement(

settlement_id BIGINT PRIMARY KEY,

payment_id BIGINT,

released_amount DECIMAL(18,2),

released_at TIMESTAMP,

approved_by BIGINT

);
```

# 27. Acceptance Criteria

- Contract 未生效不得付款
- Gate 未通過不得撥款
- Escrow 流程完整
- Milestone 綁定正確
- Invoice 可追溯
- Refund 保留完整紀錄
- Settlement 可重建
- PGP 關聯完整
- OpenAPI 驗證通過
- SQL Migration 成功
- 單元測試覆蓋率 ≥90%
- 整合測試全部通過
