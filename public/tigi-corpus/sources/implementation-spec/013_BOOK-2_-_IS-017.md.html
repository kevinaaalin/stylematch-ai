# 2. Responsibility

AI Gateway 負責：

- Unified AI Gateway
- Model Registry
- Provider Routing
- Prompt Registry
- Embedding Service
- RAG Gateway
- Knowledge Graph Gateway
- Image Generation Gateway
- Token Accounting
- Cost Control
- Failover
- AI Audit
- AI Security

AI Gateway 不負責：

- Business Logic
- Workflow Runtime
- Governance Decision
- User Interface

# 15. SQL

```sql
CREATE TABLE ai_model_registry(

model_id BIGINT PRIMARY KEY,

provider_name VARCHAR(50),

model_name VARCHAR(100),

version VARCHAR(50),

capability VARCHAR(100),

context_window INT,

status VARCHAR(30)

);
```

```sql
CREATE TABLE ai_prompt_registry(

prompt_id BIGINT PRIMARY KEY,

prompt_code VARCHAR(50),

version_no INT,

prompt_template TEXT,

output_schema JSON,

created_at TIMESTAMP

);
```

```sql
CREATE TABLE ai_usage_log(

usage_id BIGINT PRIMARY KEY,

user_id BIGINT,

provider_name VARCHAR(50),

model_name VARCHAR(100),

input_tokens INT,

output_tokens INT,

execution_time_ms INT,

cost DECIMAL(12,6),

trace_id VARCHAR(100),

created_at TIMESTAMP

);
```
