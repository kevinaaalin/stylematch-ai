# 2. Responsibility

Workflow Engine 負責：

- Governance Workflow
- Stage Management
- State Transition
- Step Execution
- Workflow Version
- Workflow Instance
- Workflow History
- Timeline
- Workflow Audit
- Event Publishing

Workflow Engine 不負責：

- Gate Decision（IS-009）
- Checklist（IS-010）
- Evidence（IS-011）
- Contract（IS-012）
- Payment（IS-013）

---

# 3. Business Rules

WF-001

每個 Case 僅有一個 Active Workflow Instance。

---

WF-002

Workflow Version 不得修改。

---

WF-003

Workflow 一律採 State Machine。

---

WF-004

禁止跳步。

---

WF-005

所有 Transition 必須 Audit。

---

WF-006

所有 Transition 必須具有 Trace ID。

---

WF-007

Transition 必須由 Gate 驗證。

---

WF-008

Workflow 結束後不可重新啟動。

---

WF-009

Workflow 可中止（Cancelled）。

---

WF-010

Workflow 可恢復（Resume）。

# 10. SQL

```sql
CREATE TABLE workflow_instance(

workflow_id BIGINT PRIMARY KEY,

case_id BIGINT NOT NULL,

workflow_version VARCHAR(30),

current_stage VARCHAR(20),

status VARCHAR(30),

created_at TIMESTAMP,

updated_at TIMESTAMP

);
```

```sql
CREATE TABLE workflow_transition(

transition_id BIGINT PRIMARY KEY,

workflow_id BIGINT,

from_stage VARCHAR(20),

to_stage VARCHAR(20),

operator_id BIGINT,

trace_id VARCHAR(100),

transition_time TIMESTAMP

);
```

```sql
CREATE TABLE workflow_history(

history_id BIGINT PRIMARY KEY,

workflow_id BIGINT,

stage_code VARCHAR(20),

status VARCHAR(30),

remark TEXT,

created_at TIMESTAMP

);
```
