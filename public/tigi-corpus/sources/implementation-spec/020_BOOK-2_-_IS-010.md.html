# 2. Responsibility

Checklist Engine 負責：

- Checklist Template
- GS-01~GS-24 Runtime
- Checklist Execution
- Item Validation
- Completion Calculation
- AI Assisted Inspection
- Dynamic Checklist
- Checklist Version
- Checklist Audit
- Checklist Report

Checklist Engine 不負責：

- Evidence Storage（IS-011）
- Gate Decision（IS-009）
- Workflow Runtime（IS-007）
- State Machine（IS-008）

# 13. SQL

```sql
CREATE TABLE checklist_template(

template_id BIGINT PRIMARY KEY,

template_code VARCHAR(50),

template_name VARCHAR(255),

workflow_stage VARCHAR(20),

version_no INT,

published BOOLEAN

);
```

```sql
CREATE TABLE checklist_item(

item_id BIGINT PRIMARY KEY,

template_id BIGINT,

gs_code VARCHAR(20),

item_code VARCHAR(50),

description TEXT,

mandatory BOOLEAN,

weight INT,

ai_supported BOOLEAN

);
```

```sql
CREATE TABLE checklist_execution(

execution_id BIGINT PRIMARY KEY,

workflow_id BIGINT,

template_id BIGINT,

completion_rate DECIMAL(5,2),

status VARCHAR(30),

verified_by BIGINT,

verified_at TIMESTAMP

);
```
