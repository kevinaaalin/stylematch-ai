# 2. Responsibility

Evidence Engine 負責：

- Evidence Vault
- Evidence Upload
- Evidence Verification
- Evidence Versioning
- SHA-256 Integrity
- EXIF Validation
- Digital Signature
- Metadata Extraction
- PGP Binding
- Immutable Storage
- Evidence Lifecycle
- Chain of Custody

Evidence Engine 不負責：

- Workflow Runtime（IS-007）
- State Machine（IS-008）
- Gate Decision（IS-009）
- Business Document Editing

# 8. EXIF Validation

照片必須解析：

- DateTimeOriginal
- GPS Latitude
- GPS Longitude
- Device Model
- Orientation
- Image Size

驗證：

- GPS 是否合理
- 時間是否合理
- 是否遭修改
- 是否重複

---

# 9. Chain of Custody

保存：

```text
Uploader

Verifier

Viewer

Downloaded By

Referenced By

Exported By

Every Timestamp
```

所有 Evidence 必須可重建完整生命週期。

# 15. SQL

```sql
CREATE TABLE evidence_master(

evidence_id BIGINT PRIMARY KEY,

case_id BIGINT,

workflow_id BIGINT,

stage_code VARCHAR(20),

version_no INT,

sha256 CHAR(64),

storage_uri VARCHAR(500),

content_type VARCHAR(100),

file_size BIGINT,

status VARCHAR(30),

created_at TIMESTAMP

);
```

```sql
CREATE TABLE evidence_metadata(

metadata_id BIGINT PRIMARY KEY,

evidence_id BIGINT,

gps_latitude DECIMAL(10,7),

gps_longitude DECIMAL(10,7),

device_model VARCHAR(100),

capture_time TIMESTAMP,

exif_json JSON

);
```

```sql
CREATE TABLE evidence_chain_of_custody(

custody_id BIGINT PRIMARY KEY,

evidence_id BIGINT,

operator_id BIGINT,

action VARCHAR(50),

trace_id VARCHAR(100),

created_at TIMESTAMP

);
```
