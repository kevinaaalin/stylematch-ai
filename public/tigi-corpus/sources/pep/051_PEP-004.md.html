# 06 SQL

```sql
CREATE TABLE contract_master(

contract_id BIGINT PRIMARY KEY,

case_id BIGINT NOT NULL,

contract_no VARCHAR(40) UNIQUE,

contract_version INT,

contract_status VARCHAR(30),

signed_at TIMESTAMP,

created_at TIMESTAMP

);
```

---

```sql
CREATE TABLE payment_plan(

payment_plan_id BIGINT PRIMARY KEY,

contract_id BIGINT,

milestone_no INT,

payment_percent DECIMAL(5,2),

planned_amount DECIMAL(18,2),

status VARCHAR(30)

);
```

---

```sql
CREATE TABLE payment_record(

payment_id BIGINT PRIMARY KEY,

contract_id BIGINT,

payment_plan_id BIGINT,

payment_amount DECIMAL(18,2),

payment_status VARCHAR(30),

paid_at TIMESTAMP

);
```

---

```sql
CREATE TABLE change_order(

change_order_id BIGINT PRIMARY KEY,

contract_id BIGINT,

change_reason TEXT,

change_amount DECIMAL(18,2),

approved_by BIGINT,

approved_at TIMESTAMP

);
```

# 07 Milestone Definition

標準節點：

| Milestone | 對應治理節點 |
|------------|-------------|
| M1 | D1~D2 |
| M2 | D3 |
| M3 | D4 |
| M4 | D5 |
| M5 | C1 |
| M6 | C2 |
| M7 | C3 |
| M8 | C4 |
| M9 | C5 |

付款節點可依專案類型配置，不限制固定次數。

# 15 Security

- Contract Version 不可覆寫
- Payment 不可直接修改
- 所有付款均需 Audit
- Escrow 必須保留交易流水號
- 金額異動須經 Change Order
