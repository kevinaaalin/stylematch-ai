# 34 Security Rules

- 所有 API 必須經 JWT 驗證
- RBAC + ABAC 雙重授權
- 不允許直接修改 State
- 不允許直接修改 Audit
- 不允許直接修改 History
- Case No 不可重複
- Trace ID 必須存在
