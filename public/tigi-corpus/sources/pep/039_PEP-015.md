# 07 Database Standard

命名：

- snake_case
- Primary Key：`*_id`
- Foreign Key：`*_id`
- Timestamp：`created_at`、`updated_at`
- Soft Delete：`deleted_at`（適用時）

所有 Schema 必須透過 Migration 管理。

# 10 Quality Gates

- Build
- Lint
- Static Analysis
- Unit Test
- Integration Test
- Security Scan
- Dependency Scan
- License Scan
- API Contract Validation
- SQL Migration Validation

# 11 Definition of Ready（DoR）

開始開發前必須具備：

- Business Requirement 已核准
- Engineering Specification 完成
- OpenAPI 定義完成
- Database Schema 完成
- Test Case 完成
- UX 規格完成
- ADR（如適用）完成

# 12 Definition of Done（DoD）

完成條件：

- 程式完成
- Code Review 完成
- 所有測試通過
- 文件更新
- Migration 驗證
- 安全掃描完成
- 效能符合 SLA
- Release Note 完成
- Audit 已記錄
