# 11 Agent Communication Protocol（ACP）

訊息格式：

```text
Message ID

Sender

Receiver

Task ID

Payload

Priority

Trace ID

Timestamp
```

所有 Agent 間通訊均透過 ACP，不得直接互相呼叫。

---

# 12 Human-in-the-Loop（HITL）

必須人工確認：

- Contract Approval
- Payment Approval
- Workflow Override
- Governance Exception
- High Risk Decision
- Final Report

AI 僅能提出建議，不得取代人工決策。

---

# 13 Agent Governance

限制：

- 不得修改 Canonical Data
- 不得直接更新 Workflow
- 不得直接通過 Gate
- 不得直接核准付款
- 不得修改 Audit
- 不得刪除 Evidence

# 14 SQL

```sql
CREATE TABLE agent_registry(

agent_id VARCHAR(30) PRIMARY KEY,

agent_name VARCHAR(100),

agent_version VARCHAR(30),

domain VARCHAR(100),

status VARCHAR(30),

created_at TIMESTAMP

);
```

```sql
CREATE TABLE agent_task(

task_id BIGINT PRIMARY KEY,

agent_id VARCHAR(30),

case_id BIGINT,

task_status VARCHAR(30),

priority INT,

trace_id VARCHAR(100),

created_at TIMESTAMP

);
```
