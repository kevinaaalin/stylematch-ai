# ADR 20260822: R9.2.1 Field Evidence authority boundary

Status: Accepted for local candidate implementation

## Decision

Field capture, classification, mapping, construction-log generation and defect recognition are candidate-producing services. iSAFE remains the only governance authority. Original media is immutable; metadata correction creates a revision. Evidence submission is idempotent and tenant scoped. NCR requires human confirmation. CAPA closure requires accepted verification Evidence and a headquarter-authorized action.

## Consequences

The system can operate fully offline with manual capture. Missing external providers fail closed without disabling iSAFE manual upload. No candidate action can mutate Gate, payment or R5.2 state. Production claims require separate deployment, security, recovery and release evidence.
